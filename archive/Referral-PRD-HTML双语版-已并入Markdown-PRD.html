01

背景与目标Background & Goals

Atom 是一台放在家里的力量训练设备，购买决策强依赖熟人推荐。现有分享模块已经能把训练成果做成图片和链接；邀请推荐是这套分享能力上的一层薄挂载，把"推荐"从口头变成可归因、可奖励的动作。Atom is a home strength device; purchase decisions lean heavily on word of mouth. The existing sharing module already turns workouts into images and links. Referral is a thin layer on top of it, turning a recommendation into an attributable, rewardable action.

业务目标Business goal

可归因的主机订单数。这是唯一的北极星，不看点击。Attributable device orders. The only north star. Clicks are not tracked.

用户目标User goal

邀请人：一个按钮就能发出去，随时看到朋友注册 / 购买了几个、自己拿到了什么。好友：优惠自动生效，不用研究规则。Inviter: one tap to send, always see how many friends registered / bought and what they earned. Friend: the discount just applies, no rules to study.

成功指标（首季）Success metrics (first quarter)

  • 邀请页 CTA 点击率 ≥ 30%（进入页面的人）Invite page CTA rate ≥ 30% of page visitors
  • 带码注册 / 带码订单比例Share of sign-ups / orders carrying a code
  • 邀请带来的订单占主机订单 ≥ 8%Referred orders ≥ 8% of device orders
  • 每单推荐成本 ≤ 客单价 12%Cost per referred order ≤ 12% of ticket

权益与漏斗Rewards & Funnel

两段漏斗：注册 App（只计数）和购买 Atom 并激活（发奖）。两侧权益都可叠加，永远不给现金。Two-stage funnel: sign up (counted only) and buy Atom and activate (rewarded). Rewards on both sides stack. Never cash.

力度Sizing

主机 ¥1,799$249，好友侧 ¥50$10 约占 3–4%：够让人填码，不是购买理由。每成功推荐一台总成本约 ¥140$20 真实 / ¥170$25 名义，占客单价 8% 左右。Device ¥1,799$249; the friend-side ¥50$10 is 3–4%: enough to get the code entered, not a reason to buy. Real cost per referred device ≈ ¥140$20 (¥170$25 nominal), about 8% of ticket.

用词Wording

叫「抵扣金」不叫「现金」：只能在我们店里用、有有效期，不涉及个税与资质，也不在账上堆成无期限负债。PRO 月必须标出价值。Call it "credit", never "cash": redeemable only in our store, expires, so no tax withholding, no open-ended liability. Always show the Pro month's value.

累计Accumulation

PRO 月按次叠加不封顶；抵扣金按次累计，靠 90 天有效期控制敞口。权益页显示"累计 ¥150$30 可换一件配件"作为持续动力。Pro months stack without cap; credit accumulates and is bounded by the 90-day expiry. Rewards page shows "¥150$30 gets you an accessory" as the ongoing nudge.

版本与语言Editions & Language

版本决定做什么，语言决定说什么，两者正交。版本由 App Store 区 / 账号归属地判定，不用 IP；语言跟随系统，可手动改。版本配置里的字符串自带语言键，加一门语言 = 加一列，加一个市场 = 加一份配置。Edition decides what the page does; language decides what it says. They are orthogonal. Edition comes from App Store region / account home, never IP; language follows the system and can be changed. Edition config strings carry language keys, so a new language is a column and a new market is a config file.

功能需求Functional Requirements

FR-1 P0

邀请 token 与码Referral token & code

每个账号一个永久 token（Base32，无 0/O/1/I/L，4–6 位）。对外三种呈现共用一个 token：短链 bp.fit/i/7K2A、明文码 ALEX-7K2A（前缀装饰，只解析后缀）、二维码（编码短链）。One permanent token per account (Base32 without 0/O/1/I/L, 4–6 chars). Three renderings share it: short link bp.fit/i/7K2A, plain code ALEX-7K2A (prefix is cosmetic, only the suffix is parsed), QR (encodes the link).

  • 链接可带 s（场景）c（渠道）参数，仅用于分析，缺失不影响归因。Links may carry s (scene) and c (channel); analytics only, attribution never depends on them.
  • 不做一次性、不做有效期链接。No one-time or expiring links.
验收：Accept: 截图转发、翻拍二维码、手抄短链三种情况下归因仍正确attribution survives screenshot forwarding, re-photographed QR, hand-typed link
FR-2 P0

邀请页Invite page

入口：「我的」页 banner、课后报告底部、推送。自上而下：利益点 + 邀请码 → 怎么做（三步）→ 唯一 CTA → 邀请结果（注册 App / 购买 Atom 两个数 + 我的权益 + 最近动态，同一区块）。Entries: "Me" banner, bottom of the post-workout report, push. Top to bottom: benefit + code → how it works (3 steps) → the single CTA → results (sign-ups / purchases counters + my rewards + recent activity in one block).

  • 邀请码可见但不是按钮；三格与「规则」是导航。Code is visible but not a button; counters and Rules are navigation.
  • 不显示点击数。No click count.
  • 未激活设备的账号：页面可见，CTA 置灰并说明"激活 Atom 后可邀请"。Accounts without an activated device see the page with the CTA disabled and an explanation.
验收：页面只有一个可点的主按钮；数字与动态在事件后 ≤ 5 秒更新Accept: exactly one primary button; counters and activity update ≤ 5 s after an event
FR-3 P0

分享面板与两种形式Share sheet & the two forms

CTA 拉起面板，两组：邀请图（模板 T28，3:4，含 G3 身份条、产品、利益点、G4 明文码、G1 二维码）与链接（H5，带 OG / 微信 JS-SDK 卡片元数据）。每组一排去处，按版本配置；每个去处都是终点。The CTA opens a sheet with two groups: invite image (template T28, 3:4, with inviter strip G3, product, benefit, plain code G4, QR G1) and link (H5, with OG / WeChat JS-SDK card metadata). Each group lists destinations from edition config; every destination completes the action.

  • 邀请图去处点击后进预览页，可发送 / 保存。Image destinations open a preview with send / save.
  • 现有 27 个分享模板的 G1 水印二维码一律带 token（内容图挂载）。All 27 existing share templates carry the token in their G1 watermark QR (content mount).
验收：中国版图片组在上，国际版链接组在上；面板内完成分享后回到邀请页并 toastAccept: CN shows image group first, GLOBAL link first; completing a share returns to the invite page with a toast
FR-4 P0

H5 落地页H5 landing page

解析 token → 显示邀请人昵称、头像、训练凭证；判断环境（微信内 / 浏览器）与版本；显示产品、原价 → 好友价、"已自动生效"；主 CTA 购买（唤起小程序商城bodypark.com，URL 带 ref），次 CTA「先注册 App 把 ¥50$10 存起来」，底部第三方渠道输码说明。整页没有应用商店跳转。Resolves the token → shows inviter name, avatar, workout proof; detects environment (in-WeChat / browser) and edition; shows product, list → friend price, "applied automatically"; primary CTA buy (opens the mini-storebodypark.com with ref in the URL), secondary "sign up and bank ¥50$10", third-party code note at the bottom. No app-store jump anywhere on the page.

  • token 无效或邀请人不满足资格：仍显示产品页，不显示优惠，不报错。Invalid token or ineligible inviter: product page still renders, no discount, no error.
  • 明文码始终可见。Plain code always visible.
验收：首屏 ≤ 1.5 s（4G）；微信内可直接唤起小程序Accept: first paint ≤ 1.5 s on 4G; in WeChat the mini-store opens directly
FR-5 P0

好友：结算抵扣与注册存抵扣金Friend: checkout discount & banked credit

自有商城结算页显示「邀请优惠 −¥50$10」行与已应用的码，订单落库写 referral_token。带码注册 App 的账号，抵扣金 ¥50$10 入账，限主机、90 天有效，到期前 7 天推一次。Own-store checkout shows a "Referral −¥50$10" line and the applied code; the order persists referral_token. Accounts that sign up with a code get ¥50$10 credit, device-only, 90 days, with one reminder 7 days before expiry.

  • 同一账号只能享受一次好友优惠。One friend discount per account.
  • 抵扣金与结算自动抵扣二选一，不重复。Banked credit and checkout discount are the same benefit, never both.
验收：结算行、订单字段、账户余额三处一致Accept: checkout line, order field and account balance agree
FR-6 P0

激活填码Code at activation

设备配网成功后、首次训练前，一个可跳过的步骤：「有朋友的邀请码吗？」链接 / 注册来的码预填。填码即时发 1 个月 PRO 给好友；同时给邀请人发抵扣金 + PRO 并推送（如订单已确认收货；否则挂起到收货）。After pairing succeeds and before the first workout, one skippable step: "Got a friend's code?" Codes from the link / sign-up are prefilled. Entering it grants the friend 1 month Pro instantly and grants the inviter credit + Pro with a push (held until delivery is confirmed if not yet).

  • 激活后 7 天内可在 App 内补填（一次）。Backfill allowed once within 7 days in the app.
  • 自己的码、已用过的账号、邀请人未激活设备：提示原因，不发奖。Own code, account already redeemed, inviter without activated device: explain, no reward.
验收：填码到 PRO 到账 ≤ 3 s；邀请人推送 ≤ 1 minAccept: code to Pro ≤ 3 s; inviter push ≤ 1 min
FR-7 P1

邀请明细与我的权益Invite details & My rewards

Rewards: credit balance and expiry, Pro months and expiry, earned list, "¥150$30 gets an accessory" progress.

验收：昵称按语言脱敏；纯注册标"仅计数"Accept: names masked per language; sign-up-only rows say "counted only"

归因规则Attribution Rules

业务只需要一个数：通过邀请带来的主机订单。两条来源相加，全部确定性，不做概率匹配，不接安装归因 SDK。The business needs one number: device orders brought by referral. Two deterministic sources, no probabilistic matching, no install-attribution SDK.
